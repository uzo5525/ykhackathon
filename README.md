# 깃발 대항전 AI 에이전트 — 2026 연고전 AI 해커톤

턴제 점령 게임 「깃발 대항전」(160턴, 2팀 대결)에 출전한 Python 봇과, 이를 개발하며 만든 시뮬레이터·자동 실험 파이프라인이다.
최종 제출본(v45)은 v1부터 시작한 45번의 반복 개발과 수십만 경기의 자동 실험, 실전 리플레이 역추적을 거쳐 선정했다.

## 하이라이트
- **2턴 앞을 보는 경제 성채**
  - 경제 건물 방어 인원을 정할 때 "다음 턴 도달 적"이 아니라 "반경 2~3칸 안 적 전투병"까지 미리 세어 한 턴 먼저 병력을 올린다.
  - 이 한 줄 변경으로 직전 버전 상대 70.2%(2,000경기)를 기록했다.
- **실전 리플레이 48경기 역추적**
  - 로컬에서는 강했지만 실전에서 12전 전패한 원인을 숫자로 규명했다.
  - 깃발병 과다 운용으로 경기당 18.8기를 잃었고, 그중 93~97%가 상대의 전투병 수비망 안에서 죽었다. 전투병 약 40기분의 자원이 샌 셈이다.
- **검증 체계 개편**
  - 자기 계열 봇끼리의 대전은 과적합을 낳았다.
  - 그래서 실전형 상대(깃발병 4~6기 + 사냥)를 흉내 낸 "메타 샌드백"을 포함한 15~17종 상대 풀의 평균, 같은 시드 쌍비교로 판정하도록 바꿨다.
- **실패 기록**
  - 기각한 아이디어 30여 개와 롤백 2건(v33, v46)을 모두 수치와 함께 남겼다(`docs/`).

## 핵심 설계
- **깃발병(F)은 적게·안전하게, 전투병(W)은 많이·F 곁에**
  - 동시 F는 6~7기로 묶는다.
  - F가 진입하는 칸마다 반경 2칸 안의 W를 최대 12기까지 같은 턴에 동행시킨다. 전투가 W끼리 1:1 상쇄되기 때문에, 진입 칸에서 수가 많으면 F가 살아남는다.
- **사냥**: 적 F 주변 호위보다 1기 이상 많은 W를 반경 5칸에서 모을 수 있으면 추격한다.
- **경제 성채와 상주 수비대**: 우리 학생회관·공학관마다 W를 2기 이상 상주시키고, 적 F가 다가오면 2턴 선계산으로 증원한다.
- **K 진영 미러**: 점대칭 맵을 180° 회전해 항상 한 진영 관점에서 판단한다.

## 실행에 대해
- 대회 측이 배포한 스타터 킷 파일(`campus_bot.py`, `protocol.py`, `_generated.py`, `search.py`)은 저작권이 주최 측에 있어 포함하지 않았다.
- 실제 대회 맵과 리플레이도 다른 팀 데이터가 포함되어 있어 제외했다.
- 따라서 이 저장소는 코드 열람과 설계 참고용이며, 그대로는 실행되지 않는다.
